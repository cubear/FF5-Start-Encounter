# FF5-Start-Encounter
A mod for FF5 (SNES) to force encounters by pressing the start button. Start held down.


Start_Encounter leaves the encounter rate as per normal, with encounters forced by pressing start.
Only_Start_Encounter will cause the game to have no non-event encounters, with an encounter being forced when you press start.

To be applied on a 4MB (32mbit) expanded, headerless Final Fantasy 5 rom.
